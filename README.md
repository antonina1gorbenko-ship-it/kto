# Комп’ютерні технології в освітньому процесі

Електронний навчальний посібник для здобувачів освіти спеціальності «Професійна освіта».
Укладачка: А. Горбенко, 2026.

## Структура

```
index.html            титульна сторінка зі змістом
lecture-01.html       лекції 1–15 (лекція 8 — повна, решта — заготовки)
...
lecture-15.html
assets/css/style.css  спільні стилі всіх сторінок
assets/js/course.js   назви та статуси лекцій, меню, навігація, тема
assets/js/lecture.js  тести, завдання, прогрес
assets/img/hero-net.svg  декоративна мережа в шапці
.nojekyll             вимикає обробку Jekyll на GitHub Pages
```

## Публікація на GitHub Pages

1. Створіть новий репозиторій (наприклад, `kt-posibnyk`), тип Public.
2. Натисніть **Add file → Upload files** і перетягніть **вміст** папки `posibnyk` (не саму папку). Збережіть — **Commit changes**.
3. Відкрийте **Settings → Pages**, у розділі **Build and deployment** оберіть **Deploy from a branch**, гілку `main`, папку `/ (root)` → **Save**.
4. За 1–2 хвилини посібник буде доступний за адресою `https://<ваш-логін>.github.io/kt-posibnyk/`.

## Як дописати лекцію-заготовку

1. Відкрийте потрібний файл `lecture-NN.html` (на GitHub — значок олівця ✎).
2. Замініть блоки `<div class="draft">…</div>` на свій текст. Готові блоки (схема, таблиця, картки, кейс, виноска, промпт) копіюйте з `lecture-08.html`.
3. Тест: змініть запитання й варіанти; `data-correct` — номер правильної відповіді, відлік від 0.
4. Видаліть з шапки рядок із позначкою «Заготовка» (`meta-chip draft-chip`).
5. У файлі `assets/js/course.js` змініть для цієї лекції `status: 'draft'` на `status: 'ready'`.

## Як змінити назву лекції

Назви в меню, змісті та навігації беруться з `assets/js/course.js`. Заголовок у шапці самої лекції (`<h1>`) та `<title>` змінюйте у файлі лекції.

## Прогрес

Позначки тестів і завдань зберігаються в браузері здобувача освіти (localStorage) — без реєстрації та без збирання персональних даних.
